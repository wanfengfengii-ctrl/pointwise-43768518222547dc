# tv — 一维加权全变分（TV）去噪

`tv.denoise(y, weights, penalties)` 返回唯一最小化

```
f(x) = Σ_i weights[i]·(x[i] − y[i])² / 2  +  Σ_i penalties[i]·|x[i+1] − x[i]|
```

的完整浮点列表 `x`（`n = len(y)`，`len(weights) = n`，
`len(penalties) = max(n−1, 0)`，`0 ≤ n ≤ 200000`）。
由于 `weights[i] ≥ 0.1 > 0`，目标强凸，最小值唯一。
仅使用 Python 3 标准库；空输入返回 `[]`，非法输入抛 `ValueError`，
且不修改输入。

## 算法与状态说明

沿链做动态规划（Johnson 2013, fused lasso 的 DP 算法）。
记 `F_k(t)` 为前 `k+1` 个样本且 `x[k] = t` 时的最优代价。
`F_k` 凸且分段二次，其导数 `φ_k = F_k'` 连续、严格递增、分段线性。
Bellman 递推中的 `min_s F_k(s) + λ_k|t − s|` 是 Moreau 包络，
作用于导数即"裁剪"：

```
φ_{k+1}(t) = clip(φ_k(t), −λ_k, +λ_k) + w_{k+1}·(t − y_{k+1})
```

前向扫描维护的状态：

* `knots`：双端队列，元素为 `[位置, 存储值, 存储斜率]`，按位置有序地
  描述 `φ` 的分段线性函数；裁剪只从两端删除结点、在两端各插入至多
  一个新结点，因此每个结点（≤ 2(n−1) 个）至多入队、出队一次；
* 惰性线性项：`φ_true(t) = φ_stored(t) + A·t + B`，把 `w·(t − y)`
  加到 `φ` 上只需 O(1)（`A += w; B -= w·y`）；
* `s0` / `c0`：最左段斜率与锚点值（结点表为空时使用）；
* `tminus[k]`、`tplus[k]`：`φ_k = ∓λ_k` 的两个裁剪点，供回代使用。

不变式：`φ_k` 每段真实斜率 ≥ `w[k] ≥ 0.1 > 0`，故 `φ_k` 严格递增，
每个交叉点存在且唯一，任何除法分母不为 0（`λ_k = 0` 时两个裁剪点
自然重合，无需特判）。

扫描结束后 `x[n−1]` 为 `φ_{n−1}` 的唯一零点，再回代
`x[k] = clip(x[k+1], tminus[k], tplus[k])`。

## 复杂度

* 时间：均摊 **O(n)**（每个结点至多入/出队一次，每步其余工作 O(1)），
  优于要求的 O(n log(n+2))；不反复扫描全部前缀，不构造稠密矩阵。
* 辅助空间：**O(n)**（结点队列 ≤ 2(n−1) 条，两个交叉点数组与 `x` 各 n）。

## 正确性核验（`verify_tv.py`）

* 题目小例：`[0,4],[1,3],[1] → [1, 11/3]`；惩罚改 0 → `[0,4]`；
  空输入、单点、零惩罚、常数信号、超大惩罚等边界情形。
* **KKT 残差核验**：令 `z_i = Σ_{k≤i} w_k(x_k−y_k)`，强凸问题的 KKT
  条件（充要最优性证书）为 `z_{n−1}=0`、`|z_i| ≤ λ_i`、
  互补松弛 `min(λ_i−|z_i|, |x_{i+1}−x_i|)=0`、符号一致
  `z_i·(x_{i+1}−x_i) ≥ 0`。对 n 最大 5000 的随机实例（含边界取值），
  实测最大残差 ~1e-6 量级。
* **独立小例对照**：对 n ≤ 6 枚举全部跳变符号模式（±1/0），
  把 KKT 化为线性方程组精确求解，与 `denoise` 的目标值和解逐点一致
  （目标值相对差 ~5e-8，解最大差 ~2e-10）。
* 非法输入（非列表、布尔、NaN/inf、越界、长度不符、n>200000）
  均抛 `ValueError`，且输入不被修改。

## 演示与实测（`demo_tv.py`）

* 阶跃信号 + 高斯噪声：RMSE 0.81 → 0.18，阶跃沿保留（ASCII 图）；
  逐点权重/局部放松惩罚的加权变体：RMSE 0.66 → 0.06。
* 规模倍增实测（n = 12500 … 200000）：耗时比 ≈ 2.0（线性），
  tracemalloc 峰值辅助内存同步倍增（线性），20 万点 KKT 残差 ~1e-4
  （对偶变量尺度 1e4，相对 ~1e-8），逐点误差容限
  1e-6×(1+max|y|) ≈ 1e-2 有三个数量级余量。

## 运行

```
python3 verify_tv.py   # 全部正确性核验
python3 demo_tv.py     # 去噪演示 + 20 万点倍增耗时/峰值内存实测
```
